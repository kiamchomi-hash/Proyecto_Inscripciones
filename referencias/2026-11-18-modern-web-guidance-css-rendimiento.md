# Referencias: Modern Web Guidance, CSS y rendimiento

- https://github.com/GoogleChrome/modern-web-guidance — catálogo y guías `css`, `css-layout` y `performance`, recuperadas con la CLI local.
- https://web.dev/articles/vitals — define LCP, INP y CLS, sus umbrales, el percentil 75 y la diferencia entre datos de campo y laboratorio.
- https://developer.chrome.com/docs/devtools/performance — guía de captura y lectura de trazas de rendimiento; las métricas de esta revisión no simularon CPU móvil.
- https://www.siglo21sur.com/ — producción, página de inicio medida.
- https://www.siglo21sur.com/teclab — producción, landing Teclab medida.
- https://www.siglo21sur.com/clases-apoyo — producción, catálogo de apoyo medido.
- https://www.siglo21sur.com/carreras/abogacia — producción, ficha de carrera medida; se observó la descarga de la fuente Unbounded.
