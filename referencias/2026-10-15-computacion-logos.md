# Referencias de logos de Programación

- https://www.python.org/community/logos/ — identidad original de Python; no se usa el wordmark horizontal para no achicar el símbolo.
- https://www.python.org/psf/trademarks-faq/ — política de uso identificativo de Python, sin asociación ni aval.
- https://raw.githubusercontent.com/devicons/devicon/master/icons/python/python-original.svg — variante compacta del símbolo original de Python (Devicon, MIT).
- https://github.com/isocpp/logos — C++ por Jeremy Kratz, licenciado por The Standard C++ Foundation; copia de cpp_logo.svg sin cambios gráficos. El README no especifica licencia abierta, no se presume CC0/MIT.
- https://www.w3.org/html/logo/ — HTML5 Logo by W3C, Creative Commons Attribution 3.0, sin modificaciones gráficas.
- https://github.com/CSS-Next/logo.css — CSS de Javi Aguilar y CSS-Next Community Group, CC0; archivo css.svg, violeta original.
- https://github.com/voodootikigod/logo.js — logo comunitario de JavaScript de JSConf, MIT; no se presenta como marca oficial del estándar.
- https://www.postgresql.org/about/policies/trademarks/ — identidad y política de Slonik; uso identificativo de la tecnología, sin aval ni patrocinio. Marca de PostgreSQL Community Association of Canada.
- https://raw.githubusercontent.com/devicons/devicon/master/icons/postgresql/postgresql-original.svg — variante SVG compacta de Slonik (Devicon, MIT), colores sin cambios.
- https://github.com/devicons/devicon/blob/master/LICENSE — licencia MIT conservada junto a las copias de Python/PostgreSQL. No sustituye derechos de marca.

SQL usa un símbolo neutro de base de datos creado para esta página: no es un logo oficial ni representa MySQL, SQL Server u otro proveedor. Los SVG son locales, sin scripts ni referencias externas; sólo se quitó declaración XML/DOCTYPE de los archivos que la traían. Se conservan licencias MIT y CC0 junto a los recursos. No se modifican colores ni proporciones. Recursos descargados el 15/10/2026.
